# nb-vip

Sistema VIP completo para FiveM con moneda virtual (coins), codigos canjeables y tienda de paquetes, items y vehiculos.

---

## Caracteristicas

- 🪙 **Moneda Virtual (Coins)** — Balance persistente por jugador, historial de transacciones y limites configurables.
- 🎁 **Paquetes VIP** — Paquetes con recompensas combinadas: items, vehiculos, dinero, permisos y acciones custom.
- 🏷️ **Codigos Canjeables** — Genera codigos de coins o paquetes con usos maximos y expiracion.
- 🛒 **Tienda Individual** — Compra de items y vehiculos sueltos con coins.
- 🛡️ **Panel de Admin** — Dar/quitar coins, generar codigos, ver estadisticas y gestionar codigos activos.
- 🌐 **Multi-framework** — Compatible con ESX y QBCore via nb-bridge.
- 📦 **Multi-inventario** — ox_inventory, qb-inventory, qs-inventory y defaults de framework.
- 🚗 **Multi-garage** — esx_garage, qb-garages, lunar_garage o garage custom.
- 🔔 **Discord Webhooks** — Notificaciones de compras, canjes y acciones de admin.
- 🌎 **i18n** — Textos en espanol e ingles, extensible a otros idiomas.
- 🖥️ **Interfaz NUI** — UI moderna con Vue 3.

## Compatibilidad

| Requisito | Versiones |
|-----------|-----------|
| **Framework** | ESX Legacy (1.9+) / QBCore |
| **Base de datos** | oxmysql |
| **Bridge** | nb-bridge |
| **Inventario** | ox_inventory, qb-inventory, qs-inventory o default |
| **Garage** | esx_garage, qb-garages, lunar_garage o custom |
